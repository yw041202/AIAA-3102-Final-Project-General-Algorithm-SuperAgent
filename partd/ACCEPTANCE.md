## 复现方式

工作目录为 project/partd：

```powershell
$dPython = 'python'
$env:PYTHONIOENCODING = 'utf-8'
$env:PYTEST_DISABLE_PLUGIN_AUTOLOAD = '1'
$env:PARTC_ROOT = (Resolve-Path .deps/partc/partc).Path
New-Item -ItemType Directory -Force runs | Out-Null
& $dPython -m pytest -q -p no:cacheprovider --basetemp runs/pytest-reproduce
& $dPython examples/acceptance_demo.py --output runs/demo-reproduce --partc-root $env:PARTC_ROOT
```

Demo 输出目录须不存在。测试应使用短临时目录，避免部分 Windows 环境默认临时路径加实验层级后超过路径长度限制；本轮没有修改操作系统设置。

历史完整运行结果保存在原本机的 runs/acceptance-20261115-final，不提交到 Git。分支保留 [V0.1 兼容性夹具](evidence/demo-run)、[摘要](evidence/demo-run/acceptance_summary.json) 和 [测试记录](evidence/test-results.xml)。完整产物可用上面的 Demo 重新生成；原本机绝对路径已从公开摘要移除。
