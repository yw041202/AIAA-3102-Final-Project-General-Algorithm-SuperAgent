## 已验证范围

- 真实 C 子进程执行统一 train/predict；原数值、B 表格/文本路径继续可用。
- 两个冻结骨干、LR/SVM 分类头、RGB/灰度与多分类；骨干状态不变，standard 缩放仅拟合训练集。
- 自定义验证主指标及方向、LR 的 log_loss/多分类 roc_auc；缺失概率的非法配置返回结构化失败。
- 同一骨干换分类头命中缓存；标签分配改变但类别数量不变、原路径下图片改变时缓存失效。
- 模型及缓存损坏拒绝加载，重复实验不覆盖已有结果，训练/验证图片完全相同时拒绝继续。
- 策略覆盖基线、局部调参、重复/失败记录、指标方向、预算及停止；耗时剪枝限定其他头部设置相同。
- 自动生成三分类图片，经策略建议训练两个候选，缓存命中序列为 false/true；选择落盘后复制完整模型，在新 C 进程中从仅含图片和 ID 的输入预测，与保存前一致；无训练清单、无标签、无重新拟合。
