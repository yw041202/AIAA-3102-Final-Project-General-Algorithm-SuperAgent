## 数据与范围

- 老师 train/val 保持原文件字节，开发目录没有其 test 文件。
- [Adult](https://archive.ics.uci.edu/dataset/2/adult)、[AG News](https://huggingface.co/datasets/fancyzhx/ag_news) 从原训练部分去重后，各固定抽取 10000/2000 条训练/验证，原测试仅最终使用。
- [Dry Bean](https://archive.ics.uci.edu/dataset/602/dry+bean+dataset) 在代码和策略冻结后准备；原 13611 条，去重后 13543 条，固定分层划为 9479/2032/2032，七类、16 个数值特征。
- 开发驱动不是 A 的 LLM 规划器；无收费 LLM 调用，无老师 test 调参/评分，A/B/C 源码未改。

全部 CPU 运行，累计拟合约 17.4 分钟，首个训练到实际模型包可移植验收约 29.5 分钟，不含准备。训练子进程采样 RSS 峰值约 438 MiB，不是全机内存或硬限制。环境继承已有科学计算栈，验收针对实际使用路径，不宣称全部未使用的继承包均已做依赖一致性验收。
