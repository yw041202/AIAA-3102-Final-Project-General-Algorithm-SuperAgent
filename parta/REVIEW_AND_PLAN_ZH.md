## 检查发现的缺口

1. 缺少 A 的统一入口、实验规划、结果反馈、停止及最终选择流程；D 明确将选择责任留给 A。
2. D 当前只接受 B 的表格/文本特征，图像预处理已存在，但图像训练尚未实现。因此不能称整个项目已全部完成。
3. C 原执行器在 Windows 超时路径调用 os.killpg，会失败。本次添加 Windows 进程树终止分支，保留 POSIX 行为。
4. C 原输入 token 预估按字符数除以四，可能低估中文提示词。本次改为保守 UTF-8 字节计数加消息开销；这仍不是模型官方 tokenizer，真实费用以返回的实际用量为准。
5. C 内部重试共享一次调用记录，不适合直接证明每次网络尝试的计费情况。A 将内部重试设为零，并在失败或用量不确定时停止继续调用，保留已有模型。
6. 模型注册表来自 C 的提交。2026-11-22 核查 [DeepSeek 官方更新记录](https://api-docs.deepseek.com/updates/)确认 DeepSeek-V4.1-Flash-1017 于 2026-10-17 更新；[官方价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)当前显示高峰标准输入/输出分别为每百万 token 2/8 元，与 C 的条目一致，故优先选用该模型。当前网页不是 10 月 21 日历史快照，正式提交仍应保存课程日期对应的价格依据。其他注册表条目未经本次逐一复核；服务商是否接受固定版本 ID 需在获知 base URL 后验证。
7. 课程原始数据及任务公告尚未提供给本次运行。预测目前沿用 D 的 sample_id/prediction 格式，需对照公告确认。
